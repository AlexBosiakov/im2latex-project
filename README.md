Im2LaTeX Project

Проект по распознаванию математических выражений с изображений и преобразованию их в LaTeX-форму.  
Модель использует энкодер на основе сверточной нейросети (CNN) или ResNet‑18 и декодер на основе LSTM.  
Для генерации применяется beam search и greedy‑декодирование, а для оценки — точное совпадение и метрики схожести.

Описание
Модель принимает изображение математического выражения и генерирует соответствующую LaTeX‑строку.  
Это полезно для цифровизации рукописных заметок, автоматизации ввода формул и создания обучающих систем.

Проект включает:
- обучение модели на датасете CROHME
- предсказание формул с помощью beam search
- оценку качества генерации
- вспомогательные скрипты для анализа, нормализации и проверки данных

Структура проекта

Основные файлы:
Im2LatexModel.py — архитектура модели с простым CNN‑энкодером и LSTM‑декодером  
resnet_model.py  — альтернативная реализация модели с ResNet‑18 энкодером  
train_im2latex.py — обучение модели на размеченных данных  
evaluate_model_beamsearch.py — оценка модели на тестовой выборке с beam search  
dataset_crohme.py — загрузка изображений и аннотаций из JSON  
eval_soft_metric.py — вычисление метрики схожести между предсказанием и ground truth  
predict_single.py — предсказание формулы для одного изображения  
examples_topk.py — вывод top‑k предсказаний для анализа beam search  
test_beam.py — тестирование beam search на отдельных примерах  
test_greedy.py — тестирование greedy‑декодирования  
train_resnet_lstm.py — обучение модели с ResNet‑энкодером

Вспомогательные файлы:
IMG_norm.py — нормализация изображений  
Parsing.py — парсинг аннотаций  
ProvercaDataset.py — проверка корректности датасета  
ProvercaModel24.py — отладка модели на конкретном чекпоинте  
img_form.py — преобразование изображений  
kolvo.py — подсчёт статистики по токенам  
test_checkpoint30.py — тестирование модели на 30‑м чекпоинте  
test.py — вспомогательный тестовый скрипт

Данные:
train.json, val.json, test.json — аннотации для обучающей, валидационной и тестовой выборок

Результаты тестов
- ResNet18 (50 эпох):
  - Exact Match: 0%
  - Среднее сходство (Soft metric): ~33.3%
  - Примеры со схожестью ≥ 80%: ~0.1%
- Im2Latex (30 эпох):
  - Exact Match: 0%
  - Среднее сходство (Soft metric): ~8.9%

Вывод: модель на основе ResNet18 показывает заметно более высокое качество по метрике сходства (33% против 9%), хотя обе модели пока не достигают точных совпадений.
Это указывает на необходимость дальнейших улучшений архитектуры и обучения.
